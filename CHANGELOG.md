## [1.0.0] - 2026-10-20

### Added

- Read-only static analysis for files and recursive directory trees.
- Validated, severity-aware literal and regex rule packs.
- ASCII and UTF-16 string extraction for binary files.
- MD5, SHA-1, SHA-256, entropy, file-signature, and IOC metadata.
- Human-readable, JSON, and SARIF 2.1.0 reports.
- CI failure thresholds and bounded resource controls.
- Python 3.9+ compatibility, strict typing, and a 90% coverage gate.

### Changed

- Replaced the original interactive Bash prototype with an installable Python package and CLI.
